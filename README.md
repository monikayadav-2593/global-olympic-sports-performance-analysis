# Global Olympic Sports Performance Analysis Dashboard

A Flask web application that presents an interactive Tableau Public story about Olympic athlete performance and medal results.

## Features

- Embedded Tableau Public story with country-level medal totals and medal category breakdowns.
- Responsive page layout for desktop and mobile screens.
- Flask route that renders the dashboard template.

## Requirements

- Python 3.8 or newer
- Flask

## Run locally

From the project directory, create and activate a virtual environment if desired, then install Flask and start the server:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install Flask
python app.py
```

Open [http://127.0.0.1:5000](http://127.0.0.1:5000) in a browser. The embedded visualization is hosted by Tableau Public, so an internet connection is required to load it.
